# PocketWorld 设计规范

给设计师和做 UI 的人看的。工程侧的实现约定在 `docs/`,不在这里。

## 怎么看

`ui-spec.html` 是**自包含单文件**(无外部依赖、无网络请求),下载后双击就能在浏览器打开。
GitHub 网页上直接点开只会看到源码 —— 用下面任一种方式:

```bash
# 克隆后本地打开
open design/ui-spec.html
```

或在 GitHub 上点 **Download raw file** 存到本地再打开。

## 里面有什么

| 章 | 内容 |
|---|---|
| 01 色彩 | **纯白 + 纯黑 + 三档灰,共五个中性色**;红黄绿另算;三维编辑舱同一原则(纯黑 + 白的三档) |
| 02 字号 | 六级阶梯 + 一个品牌例外(字标) |
| 03 间距 | 七级,4 的倍数 |
| 04 圆角 | 四级 + 三种按钮规格 |
| 05 图标 | 三档尺寸、与文字的间距、命中区 44 |
| 06 功能分区 | 三维编辑舱五个区(附手势归属)、资料库网格 |
| 07 动效 | 三个时长、一条曲线、惯性参数 |
| 08 偏离清单 | 现有页面里要改回来的地方,逐条实测 |

## 这本册子是目标态

每章给的阶梯是**唯一正确取值**,不是现状清单。现有页面有一批偏离项,逐条记在第 08 章,那是迁移待办。

做新界面时:先在册子里找到对应阶梯,取整到最近的一级。**阶梯里没有的值就是不允许的值** —— 需要新增一级时改这本册子,而不是在页面里破例。

## 中性色只有五个

```
paper    #FFFFFF   页面底 · 卡片 · 弹层(同一个白)
ink      #000000   主文字 · 主按钮底 · 图标
gray-1   #6B6B6B   次要文字 · 说明
gray-2   #9B9B9B   时间戳 · 占位 · 禁用
gray-3   #E4E4E4   分隔线 · 卡片描边
```

浅填充(分段控件槽底、按下态)用 `ink` 的低不透明度派生,**不新增第四档灰**。
红 / 黄 / 绿是状态色,另算 —— 它们承担的是完全不同的职责。

⚠️ **页面底和卡片是同一个白 ⇒ 卡片必须有 1px `gray-3` 描边。**
此前卡片靠"白压在暖白上"那 2% 差异浮起来,统一成纯白后这个手段没了。
这是本次收敛唯一带来新增工作量的一条。

## 与代码的关系

代码侧的唯一实现是 `lib/ui/design_system.dart`(`AetherColors` / `AetherSpacing` / `AetherRadii` / `AetherTextStyles`)。
本册的取值与它一致。两边不一致时**以册子为目标**,把代码改过来 —— 第 08 章列的就是这些差异。

## 尚未覆盖

插画风格、图标绘制规范(线宽/端点/网格)、应用商店素材。
这三项目前没有成体系的现状可归纳,等有了实际素材再补。册子里也明确标了不覆盖,不要当成"漏写"。
