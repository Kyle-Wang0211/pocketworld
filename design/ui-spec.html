PocketWorld UI 规范手册

一台装在 iPhone 里的三维扫描仪。它的界面分两个世界:纯白的资料库,和纯黑的三维编辑舱。这本册子把两个世界的取值收敛成可照着做的阶梯 —— 五个中性色、六级字号、四级圆角、三档图标。

00 / 怎么用

这是目标态,不是现状清单

每一章给的阶梯都是唯一正确取值。现有页面里有一批偏离项,已经逐条记在 08 偏离清单,那是迁移待办,不是可选风格。

做新界面时:先在本册找到对应阶梯,取整到最近的一级。阶梯里没有的值就是不允许的值 —— 需要新增一级时改这本册子,而不是在页面里破例。

中性色
纯白 + 纯黑 + 三档灰,共五个。红黄绿另算(状态色,见 01)
代码事实源
lib/ui/design_system.dart —— 本册的取值与它一致,它是唯一实现
本册覆盖
色彩 · 字号 · 间距 · 圆角 · 图标 · 功能分区 · 动效
不覆盖
插画风格 · 图标绘制规范 · 应用商店素材 —— 尚未成体系,别在这里假装有

01 / 色彩

五个中性色承担一切结构,彩色只用来报告状态

这台仪器的界面是黑白灰的。彩色不做装饰、不做品牌表达,只用于报告系统状态——绿色永远意味着"成功产出",红色永远意味着"需要你处理"。看到彩色就该是有事发生。

中性色 · 亮色世界(资料库、设置、草稿页)

纯白、纯黑,加三档灰。就这五个。没有第二种白、没有暖白、没有近黑 —— 想不出该用哪一档时,说明那个界面的层级本身没想清楚,不是色板不够。

页面底和卡片是同一个白 ⇒ 卡片必须有描边。此前卡片靠"白 #FFFFFF 压在暖白 #FAFAFA 上"那 2% 差异浮起来,两者统一成纯白后这个手段没了。所有卡片、弹层、内嵌面板一律 1px gray-3 描边,不靠底色差异区分层级。这是本次收敛唯一带来新增工作量的一条。

浅填充:用 ink 的不透明度,不加第四档灰

分段控件的槽底、内嵌面板需要一块比 gray-3 更轻的填充。不要为此新增灰色——用纯黑的低不透明度派生:

ink @4% · 槽底
ink @8% · 按下态
选中
ink · 选中项

不透明度派生的代价:同一个 ink @4% 叠在不同底色上算出的实际颜色不同。本册所有亮色界面的底色都是纯白,所以这里不存在歧义 —— 但如果以后引入其他底色,这些派生值要重新核对。

中性色 · 三维编辑舱(点云预览、选区编辑、拍摄)

深色舱不是"亮色世界的暗色主题",它是另一个判读场景:点云和相机取景必须在无干扰的纯黑上看。规则与亮色世界完全对称——纯黑底 + 白的三档不透明度,同一个原则,不用记两套。

02 / 字号

六级阶梯,外加一个品牌例外

字体族全程用系统字体(iOS 上是 SF Pro),不打包自定义字体 —— 中英混排的字重与标点由系统处理最稳。层级靠字号和字重区分,不靠字体族。

中文不加字距;英文全大写的 Label 加 +0.06em。数字成列时(统计、尺寸、时间)用等宽数字对齐。

03 / 间距

4 的倍数,七级

这一档不需要收敛 —— 现有阶梯本来就是标准的 4 倍数序列。要守的是别在阶梯之间取值(没有 10、没有 14、没有 20)。

级别值典型用途
xs4图标与紧邻文字之间
sm8胶囊内边距 / 紧密列表行距
md12卡片内边距 / 徽标内缩
lg16网格间隙 / 区块内间距
xl24区块之间 / 页面左右边距
xxl32大区块分隔
huge48空态上下留白

页面左右安全边距固定 xl · 24。底部工具面板贴屏幕最底边,内容靠 safe-area inset 自适应避开 home indicator —— 背景色必须铺到屏幕边缘,不能包在安全区内,否则机型不同会露出底色。

06 / 功能分区

三维编辑舱:五个区,各归其位

这是全 App 最密的一屏 —— 手势要同时喂给点云、选区框、刻度尺和骰子。分区不只是视觉安排,它决定手势归谁,画错位置会导致某块区域点不动。

区位置内容手势归属
A 顶部动作区safe-top, 左右贴边左"取消" / 右"完成"点击
B 更多菜单A 下方,与"取消"左对齐⋯ 圆形按钮 + 展开浮层点击;展开时不吞下层手势
C 视图控制列A 下方,与"完成"右对齐六视图立方体 + 四向箭头点击换面。不支持自由拖动
D 点云画布占满全屏(A/C/E 叠在其上)点云 + 选区框 + 手柄单指拖手柄改框;双指 pan / pinch 缩放
E 工具面板贴屏幕最底边把手 + "旋转"刻度尺水平拖 = 转点云。该区域从画布手势中排除
分区的硬约束:面板高度变了,画布的手势排除区必须跟着变。E 折叠后只剩把手(约 24 高),若排除区仍按展开态的 200 计算,画布下方会留一条点不动的死区。这是分区图必须画准的原因 —— 它不是装饰,是手势契约。

07 / 动效

三个时长,一条曲线

动效只用来解释空间关系——什么从哪来、去了哪。不做强调、不做趣味。

时长值曲线用在哪
即时80 mseaseOut按下态 / 高亮
过渡180 mseaseOutCubic面板折叠 / 浮层出现 / 状态切换
转场250 mseaseOutCubic页面切换 / 视角归位动画
惯性
刻度尺与可甩控件用摩擦模型,系数 0.135(与系统滚动一致)。抬手速度低也要有滑行——真人拨完会先减速再抬手
姿态过渡
三维视角切换走轴角球面插值,不要对欧拉角分量各自线性插值 —— 过极点时会绕一大圈
禁止
弹跳 / 回弹 / 超过 300ms 的装饰动画 / 无功能的循环动画

08 / 偏离清单

现有页面里要改回来的地方

下面每一条都是实测出来的,不是估计。做新界面时按前七章;碰到这些旧值时顺手改掉。

② 新增工作:所有卡片补描边

怎么防止再退回去

收敛一次不难,难的是三个月后不反弹。三条纪律:

  1. 禁止裸写颜色、字号、圆角、间距字面量 —— 一律引用令牌
  2. 加一条自动检查,扫到新增的裸字面量就拦住(白名单只放令牌定义文件自己)
  3. 需要阶梯里没有的值时,改这本册子,不在页面里破例

第 2 条最值钱。没有它,前两条会在第一次赶工时失效。
