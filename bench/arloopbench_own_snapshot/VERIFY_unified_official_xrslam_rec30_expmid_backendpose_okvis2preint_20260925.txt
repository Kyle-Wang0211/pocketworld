== 解读(装机前必须看)
1. 目标达成:后端首次/定稿位姿对陀螺的偏移从 −5.00 ms(三场一致)回到 0.00 / −0.5…−1.0 ms;线程化与单线程一致。

   相机帧推入时它之后的 IMU 还没到,OKVIS2 离散只积到最新样本、不外插;上游右端保持恰好抵消了这 5 ms。真机直播相机帧晚到,IMU 已覆盖时新版精确积到帧时刻。
2. 🔴 沿用现行 td 规则(曝光中点 + c = 3 ms)时精度回退:后端抖动 +13…+26%;7353 对 LiDAR 尺度 +1.9% → +4.8%、ATE 3.2 → 5.7 cm;
   13f5 尺度更近(−2.3% → −1.0%)但 ATE 1.6 → 2.2 cm;6d18 尺度 −2.4% → −3.3%。
3. 诊断(不改 td 规则,只在 Mac 上把相机时间戳再挪 −5 ms):三场后端抖动、尺度基本回到改前水平
   (7353 +2.25%/3.5 cm,13f5 −1.94%/1.9 cm,6d18 −2.38%/3.2 cm;抖动三场均值 −16%)⇒ 回退不是移植错误,
   是现行 td 规则(c = 3 ms 查表及其验证)定在带 −5 ms 滞后的旧积分器上,两者配套。是否重定 td 由用户决定。
