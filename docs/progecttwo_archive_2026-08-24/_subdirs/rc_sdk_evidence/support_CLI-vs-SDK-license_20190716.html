CLI vs SDK license

RealityCapture Support
  • April 27, 2018 22:19
  • Updated
Follow

RealityCapture CLI allows you to use command-line batch processing and thus automate reconstruction processes very effectively. Almost everything you can do inside the application can be scripted for the command line. You can find all commands in the Help section of the software.
Its user does not need C++ programming, only DOS / powershell / Python batch files writing skills. Note that CLI is enabled also in the Demo version and it can be also used as a common, fully-fledged application with user interface, not just via its command line. The application user interface is visible during the commands execution.
We do not support Linux with the CLI yet.

Click here for more information on the CLI pricing: http://www.capturingreality.com/Product#Buy

Reality Capture C++ Software Developer Kit (SDK) (currently not advertised on our webpage) allows seamless integration into a third-party application. It is a set of libraries designated for Windows, containing the core of RC's technology. SDK allows low-level processing. Its use requires programming skills. However, we can provide you with some tutorial samples. Having the SDK enables you to build your own application, similar to RC. Moreover, you can create custom-suited solutions for your business. 

SDK contains these core modules: 

- registration of images, laser scans and depth maps 
- 3D model reconstruction in the triangular mesh form 
- high-quality per-vertex colors' creation 
- creation of high-quality texturing for models 
- coordinate system management 
- basic sample projects
