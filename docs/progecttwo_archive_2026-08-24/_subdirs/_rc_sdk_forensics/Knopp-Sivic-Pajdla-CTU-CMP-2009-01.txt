                                             Abstract
             We seek to recognize the location of a query image given a dataset of images
         labelled with geo-location information. This is a challenging task as the imaged
         appearance of the query image can be very dierent from the appearance of im-
         ages in the database due to changes in viewpoint, lighting, and partial occlusion by
         other objects. We employ for this task the bag-of-visual-words approach with large
         vocabularies and fast spatial matching previously used for object retrieval in large
         image collections. We compare location recognition performance of several invariant
         feature detectors and investigate various design and parameter choices for building
         large visual vocabularies. Finally, we show that visual query expansion improves lo-
         cation recognition performance. Location recognition results are shown on a dataset
         of more than 1,300 geotagged omnidirectional images of Prague using a query test
         set of 25 omnidirectional and perspective images.

Performance measure              For each query test image the goal is to nd/match all training
images labelled in the ground truth as depicting the same location. Similar to evaluation
in object retrieval [10], we measure performance using the precision-recall curve. For each
query image we report average precision (AP), which is the area under the precision-recall
curve. To report a single number performance measure for the entire test set we compute
the mean average precision (mAP), which is the arithmetic mean of average precisions
across all queries.
    Note that a perfect performance (average precision of 1) is obtained when all database
images that have a visual scene overlap with the query are matched (and ranked top).
This might seem unnecessary strict for the location recognition task where only the best
matching image needs to be correct. However, this stricter measure allows us to better
assess the fall-o in matching performance between dierent variations of the location
recognition algorithm.

4 Visual vocabulary investigation
In this section we investigate several design and parameter choices for building visual
vocabularies.



4.1       Comparison of approximate nearest neighbor search methods

Here we compare two approximate nearest neighbour search methods used in the approx-
imate k-means algorithm for building large visual vocabularies. The rst method is based
on a randomized forest of kd-trees and has been previously used in [10].          The second
method is based on a hierarchical k-means tree and is implemented in the recently de-
veloped "Fast Library for Approximate Nearest Neighbor Matching (FLANN)" [9]. Note
that both methods are approximate and have logarithmic complexity in the number of
searched data points. The FLANN library includes an algorithm selection and parame-
ter conguration step with the goal of achieving the highest percentage of true nearest
neighbours found on a training dataset of descriptors [9]. The result of this optimization
procedure on our training data was selection of the hierarchical k-means algorithm with 1
tree, branching factor of 32 and 15 iterations at each level of the tree. Using both methods
we build a vocabulary of 131,072 visual words from a set of 1.92M training SURF descrip-
tors. The goal of this experiment is to test the recently developed FLANN software and
evaluate benets of its algorithm conguration procedure. Table 8 shows the performance
comparison of the two methods. The optimized hierarchical k-means tree performs better
on 7 out 11 queries and has slightly better overall performance.



4.2       Vocabulary size

Figure 3 shows the location recognition performance, measured by mean average precision,
for dierent vocabulary sizes. Similar to [10] we observe a peak in performance at around
1M visual words. Intuitively, when the number of clusters is too small, the resulting visual

6 Conclusions
We have implemented and tested the state-of-the-art bag-of-visual-word model with large
vocabularies and fast spatial matching [10] for location recognition on a database of more
than 1,300 geotagged omnidirectional images of Prague.              Using a manually obtained
ground truth for 25 query images we have benchmarked several local invariant feature
detectors and found the SURF features [3] to perform best on our data. In addition, we
have found that the hierarchical k-means tree approximate nearest neighbour search [9]
outperforms in the randomized forest of kd-trees [10] for building large visual vocabu-
laries using the approximate k-means algorithm. We have also investigated the eect of
the number of iterations of approximate k-means on the location recognition performance
and found 20 iterations to be a good compromise between the vocabulary building time

and recognition performance. Finally, we have shown that spatial verication and query
expansion [5] can signicantly improve location recognition performance.
