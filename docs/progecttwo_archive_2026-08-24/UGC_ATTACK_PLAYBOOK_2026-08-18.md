# 早期 UGC 平台崩溃与攻击作战手册

调研日期 2026-08-18 · 六路并行 + 对抗性核查（21 CONFIRMED / 6 PARTIALLY_CONFIRMED / 0 编造）
对象：PocketWorld（单人 · iOS · Flutter + Supabase · 1 用户 6 作品 · 未上架）

---

## 0. 一句话结论：**你不会破产，但你会停服，而且门槛低得惊人**

我在调研前把「账单爆炸」排在第一位，**这个排序被数据推翻了，现更正**。

Supabase 只有三种计费状态：

| 状态 | egress 配额 | 超额会怎样 |
|---|---|---|
| **Free** | 5GB uncached + 5GB cached | 邮件通知 → 宽限期 → **项目暂停 / 数据库转只读 / API 返回 402** |
| **Pro + Spend Cap ON**（默认） | 250GB + 250GB | 同样禁止继续用量，**不产生超额费用** |
| Pro + Spend Cap **OFF** | 无上限 | $0.09/GB（cached $0.03/GB），**账单无界** |

**Spend Cap 默认就是开的。** 所以在 Free 层，你收到天价账单的路径根本不存在——被打的结果是**停服**，不是破产。

> 正确的心态转换：不是「怕被打破产」，而是**「设计成被打时优雅停服，而不是优雅破产」**。
> 账单保护与可用性是硬互换，1 用户阶段唯一理性选择就是保持 cap ON。

## 1. 真正的第一杀手：**成功本身**

从生产库量出来的真实数字（不是估算）：

```
works 桶：11 个对象 · 总计 158.5MB · 平均 14.4MB · 最大 41MB
```

对照 Free 层 5GB uncached egress：

| 作品大小 | 耗尽当月免费 egress 需要 |
|---|---|
| 平均 14.4MB | **约 355 次下载** |
| 最大 41MB | **约 124 次下载** |
| 小作品 17MB | 约 301 次下载 |

**一条中等热度的 Reddit 帖子就是几千次浏览。一次 App Store 推荐位是数万次。**

也就是说：你根本不需要被攻击。**你的产品只要成功一次，当月就会因 402 对所有人关站。**
这才是「服务器崩溃」在你身上最可能的真实形态，而且它长得像好消息。

### 免费层的第二颗雷：项目自动暂停

「过去一周数据库活动不足」的免费项目会被暂停。每天几个请求即可保活；暂停后 1 年内可恢复，
但**超过 90 天就没有一键恢复按钮**。1 用户 6 作品的现在，这个雷是实打实压在头上的。

## 3. 你天然躲过的坑（对照真实事故）

| 别人怎么死的 | 你的现状 |
|---|---|
| **Parler**（2021）顺序整数 ID + 无鉴权 API → 70TB 全站被打包；且「只加 delete 标志不删内容」导致删帖全被爬；618 个视频带 GPS 元数据被反查到住址 | ✅ 全表 **UUID 主键**；✅ 删除是**真删存储对象**（admin-moderate-work / delete-work 都走 Storage API） |
| **Clubhouse**（2021）user ID 是顺序整数 → 130 万条记录被逐号扫光 | ✅ 同上，不可枚举 |
| **Tea app**（2025-07）Firebase 桶零配置、桶 URL 硬编码在 Android 客户端 → 7.2 万张验证自拍/证件照泄露，三天后再爆 110 万条私信；**Apple 已于 2025-10 将其下架**；10 起诉讼（5 起已合并） | ✅ 桶有 `file_size_limit` + `allowed_mime_types` 白名单；✅ works/scans 为**私有桶** |
| 刷浏览量灌爆数据库 | ✅ `record_work_view` 有 `(作品, 访客, 小时)` 唯一索引去重 |

> ⚠️ 但 EXIF 剥离**尚未确认**——你的 3D 扫描含用户家中场景，
> 「3D 扫描 + 拍摄地 GPS」组合泄露的是**用户住址**。Parler 正是死在这里。

## 4. 真实事故清单（全部经独立核查）

### 内容灾难

- **Lemmy CSAM 轰炸**（2023-08，CONFIRMED）— 攻击者向 lemmyshitpost 批量发 CSAM。
  因 pict-rs 默认缓存外站图片缩略图，非法内容被**自动联邦复制到所有订阅实例的硬盘上**。
  当时全生态无任何哈希扫描工具。多实例被迫全站禁用图片上传、粉碎缓存。
  攻击目的就是利用 CSAM 的法律毒性打击平台本身。

- **mastodon.xyz 被注册局停域**（2023-07，CONFIRMED）— 单管理员实例，约 3,200 月活。
  用户发布 AI 生成 CSAM，管理员**因举报队列积压未及时处理**。
  托管商转发 abuse 报告后 **2 小时内**，.xyz 注册局直接给域名挂 serverHold，**事先零通知**，整站从公网消失。
  停服约 25 小时。
  > 教训：**杀死你的第一刀来自基础设施层（注册局/托管商），远快于任何法律程序。**

- **Omegle 关站**（2023-11，CONFIRMED）— 创始人自称唯一雇员，无全职审核员（**与你处境直接可比**）。
  A.M. v. Omegle 案：法院两次驳回 Section 230 免责，因为产品责任被框定为「平台设计缺陷」而非第三方内容，
  且 FOSTA 为性贩运民事诉讼开了 230 例外。诉讼近两年后庭外和解，**关站是和解条件**。
  创始人声明：对抗滥用的 "stress and expense ... are simply too much"。
  > 教训：**单人公司死于诉讼成本，而不是败诉判决。**

- **Tumblr 被 Apple 下架**（2018-11，CONFIRMED）— 关键点：Tumblr **当时已对每张上传图跑行业哈希库扫描**，
  仍被击穿——因为新材料不在哈希库里。为回到 App Store 全站封杀成人内容，
  流量从 5.21 亿 → 3.70 亿页面访问（**30 天内跌近 1 亿，累计约 -30%**），从此一蹶不振。
  > 教训：**哈希匹配只覆盖「已知」材料，对新生成内容是结构性盲区。**

- **Telegram 被下架**（2018-02，CONFIRMED）— Phil Schiller 邮件原文确认流程：
  **立即下架 → 通报 NCMEC 与执法 → 验收整改后放行**。约 24 小时内恢复。
  > 教训：Apple 的动作是先下架再谈整改，恢复速度取决于你补救多快。

### 账单

- **Netlify $104,500 账单**（2024-02，PARTIALLY_CONFIRMED）— ⚠️ 核查修正：
  「DDoS 攻击」是受害者与媒体的定性，**Netlify CEO 明确表示流量不符合攻击模式**，
  后续调查倾向于「对同一 mp3 文件的持续下载」。最终减免至 5%（$5,225），标准做法是减到 20%。
  数字本身（3.44MB 文件 / 190TB / 单日 60.7TB）核实无夸大。
  > 死法本质：**大文件躺在按流量计费的 host 上且无封顶**——你的 3D 模型是同款靶子。

- **Milkie Way 72 小时烧 $72,000**（2020，CONFIRMED）— 设了 $7 预算告警照样烧穿，
  因为 **GCP budget 只发通知不封顶**，且计费同步延迟约 1 天。
  复盘核心数字：**max-instances 若设为 2，账单是 $144 而非 $72,000（500 倍差距）**。

- **AWS 空 S3 桶账单**（2024）— 可预测的资源名 + 任何人可直接请求 = 他人能给你制造用量。
  AWS 后来把未授权请求改为免费，**但那只救 403**——你公开桶的每次成功下载 egress 照计。

### 认证面

- **23andMe 撞库**（2023，PARTIALLY_CONFIRMED）— 14,000 账号被撞，牵连 **655 万人**的共享基因数据。
  ICO 罚款 £2.31M。⚠️ 核查修正两处：①「5 个月无人察觉」不准确，
  公司 2023-07 做过孤立调查、2023-08 曾把数据被盗说法**当骗局驳回**——ICO 判的正是「有信号不处置」；
  ②「直接导致破产」时序不通（破产 2025-03，罚款 2025-06），应弱化为「重要诱因」。

- **SMS pumping / 邮件轰炸** — Twilio 官方防欺诈处方可直接平移到邮件 OTP：
  监控「**被验证的 OTP 数 / 发出的 OTP 数**」，转化率骤降（如 75% → <2%）即正被 pump，
  直接告警熔断。

- ⚠️ **per-IP 限流的结构性盲区**（Okta 2024-04 官方公告，CONFIRMED）：
  当代撞库走 TOR + 住宅代理（NSOCKS、Luminati 等），源 IP 看上去全是普通家庭宽带，
  数百万请求分散到海量干净 IP。**按 IP 限流对此结构性失效**——
  包括 Supabase 那个 360 次/h/IP 的 verify 限额，**也包括我 08-17 加的 IP 20/h**。
  per-target（每邮箱）限频防轰炸单个受害者，CAPTCHA/attestation 防海量 IP 撒网，**两者缺一不可**。

## 5. 意外的好消息：Supabase Auth 默认限流其实很紧

| 端点 | 默认限额 | 可调？ |
|---|---|---|
| **邮件发送** | **2 封/小时（项目级）** | 仅接自定义 SMTP 后可调 |
| OTP | 30 个/小时/项目 + 同一用户 60 秒冷却 | 可调 |
| /verify | 360 次/小时/IP（突发 30） | **不可调** |
| token 刷新 | 1800 次/小时/IP | 可调 |
| 匿名登录 | 30 次/小时/IP | 可调 |

**关键含义：默认配置下邮件轰炸根本烧不动。**
风险敞口是在你**接 Resend 并调高限额的那一刻**才打开的。
⇒ **调限额与上 CAPTCHA/attestation 必须同一天做。**

## 6. 行动清单（按性价比排序）

### 🔴 立刻（阻止「成功即关站」）

1. **Cloudflare 前置公开桶** — $0 + 半天。
   缓存命中发生在 CF 边缘，**不产生 Supabase egress**；CF 官方承诺吸收攻击流量不加价。
   顺带解锁下面第 3 条（CSAM 扫描只覆盖过 CF 缓存的流量）。
   ⚠️ 必须配好 Cache Rules 让大静态资产真正命中缓存。

2. **止血 kill switch** — $0 + 几小时。**性价比最高的一项。**
   预留「一键关闭上传 / 一键关闭公开桶读取」的开关。
   Lemmy 攻击中实际救命的就是这个——**攻击进行时没有时间写代码。**

3. **egress 多阈值告警** — $0。
   ⚠️ 两条铁律：预算告警**不是**封顶（Milkie Way $7 预算烧 $72k）；
   即使真断路器也**非即时**（Vercel 官方：每几分钟检查一次，越线后仍会继续服务并计费数分钟）。

### 🟠 上架前（合规硬门槛）

4. **Cloudflare CSAM Scanning** — $0，全套餐可用。
   **2025-02-04 起取消了 NCMEC 凭证要求**，现在只需一个验证过的邮箱即可开启。
   ⚠️ 只扫经 CF 缓存的流量 ⇒ 依赖第 1 条先落地。

5. **NCMEC ESP 注册**（esp.ncmec.org/registration）— 免费。
   法律边界：§2258A(f) 明确**不要求**你主动监控或扫描；
   但一旦获得 actual knowledge 必须尽快报告，报告须保存 **1 年**（REPORT Act 2024 从 90 天延长）。
   知情不报罚款：**首次 $600,000，再犯 $850,000**（月活 1 亿以下）。

6. **升 Pro** — 拆掉免费层双雷（项目暂停 + 5GB egress 402），并解锁泄露密码拦截（HIBP）。
   保持 **Spend Cap ON**。

7. **EXIF GPS 剥离** — $0，设计期决定。3D 扫描 + GPS = 用户住址。

### 🟡 增长期

8. **App Attest**（iOS-only 结构性优势，$0）— 把敏感端点锁定到「真实 App Store 安装」。
   ⚠️ 边界要认清（WWDC26 官方口径）：避免直接用它阻止用户；
   被攻破设备仍可能产生有效 attestation；fraud risk metric 是**调查信号不是阻断依据**；
   密钥不跨重装存活（合法用户也会轮换新 key，不能见新 key 就拒）。
   **它验证「真 app + 真设备」，不验证「真人」**——真实设备农场照样能刷。

9. **审批制注册** — $0。1 个用户的平台审批成本 ≈ 0，**现在是开审批制唯一不疼的窗口期**。

10. **shadowban 而非硬删** — 新账号作品默认低可见/进审核队列；判定 spam 的账号本人视角一切正常。
    比事后清库便宜几个数量级。

11. **OTP 转化率熔断** — 半天。发/验比例骤降即暂停发送并告警。

### ⚪ 判死 / 不做

- ❌ **Turnstile / hCaptcha** — Supabase Auth 只支持这两家，但**在 Flutter 原生端都要 WebView 承载**。
  这正是 App Attest 路线要填的空档。
- ❌ **VirusTotal 免费 API** — 明文禁止商用（限 4 次/分、500 次/天，禁多账号绕限）。
  一旦商用就是违约。
- ❌ **Read Replicas** — 只读、不覆盖 Auth/Storage/Realtime、有复制滞后、自定义域不过负载均衡器。
  是量级上来后的付费选项，**不是救火工具**。
- ⏸ **PhotoDNA** — 免费但需逐案资质审查，SIO 报告指出对小平台有结构性障碍。可申请但别押注。
- ⏸ **ClamAV** — 本清单唯一非零成本项（需常驻容器/VM）。
  且 3D 模型格式的 AV 特征覆盖本来就弱 ⇒ 前两层（MIME 白名单 + magic bytes）才是主防线，可延后。
