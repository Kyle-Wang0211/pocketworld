## 0. 一句话

## 1. 战略定位(已拍板,不要再重新论证)

| 项 | 结论 | 为什么 |
|---|---|---|
| **公司形态** | **空间内容平台,靠 C 端流量** | 不是技术授权公司,不是垂直 SaaS |

| **生意类型** | **内容生意,少做工具生意** | 用户 08-21 明确。工具生意(商家付费、终端免费)只作为**纯现金流工具**,不给战略地位,判断标准=有没有在消耗做内容那条线的时间 |

## 2. 冷启动方案(用户自己提的,比任何外部建议都好)

**开比赛:征集"全国最乱的房间"**

好在四点:
1. **把隐私抗拒反转成参与动机** — "乱"不是隐私是笑点,展示不是暴露是自嘲
2. **消灭 UGC 头号杀手** — 不是降低门槛而是**反向**门槛,越糟越好
3. **3D 在这里是必需而非装饰** — 乱是空间性的(层叠、无处下脚、门后还有一堆),**2D 照片根本拍不出来**
4. 排名/对比/嘲笑是现成的传播燃料

**变现设计(用户提的):** DDL 后点赞第一名获"人民的选择 + 官方认证",该作品 **0.99 元卖门票**,同时开启创作者分成。第二三名及其他全免费 ⇒ 传播不受损,**付费墙本身变成传播素材**。

**必须配套的三件事:**
- 参赛必须用自家工具,产出留在平台上可检索(不是活动页)
- **埋 before/after**:"收拾完再扫一次" ⇒ 第二次创作 + 强传播形态 + **天然变成"一次性时刻"**,把猎奇冷启动和内容战略接上
- **提防用户属性错配** — 看热闹的人不会为"我的婚礼"付费,很多平台死在"靠猎奇起量后转不了型"

**巨大附加值:乱房间是三维重建的地狱难度场景**(严重遮挡、小物件密集、杂乱纹理、狭窄、光照差)。这是一次免费的大规模真实压测,**建议内置失败上报**,甚至单开"连算法都放弃了"奖项——把技术失败变成内容笑点,拿到最珍贵的失败样本还不掉口碑。

**必须验证的假设:** "愿意分享私人空间"的前提是**匿名**。要匿名参赛 + 默认剥离位置信息(正好与那条红线一致)。

## 3. 留存机制(爆款≠留存,这是两件事)

**关键数学:** 单内容生产/消费比是 **1.5:1 到 3:1**(用户实测:物体扫 30s 看 10–15s;组合 1min 看 20–30s;房间 3–5min 看 2–3min;App 单次扫描上限 **300 帧或 5 分钟**)。但真正的问题不在这里,在于 **1% 创作者要养 99% 消费者,而 3D 场景的重复消费率接近零**。

⇒ **有效的留存机制必须"不依赖新内容",即让老内容重新值得看:**

| 优先级 | 机制 | 开发成本 |
|---|---|---|
| 1 | **周期性主题**(本周书桌/下周冰箱/再下周后备箱) | **零**。把一次爆款变成心跳 |
| 2 | **访客反馈回流给创作者**("37人看过,平均停留1分12秒,最多人停在你书架前") | **极低**,后端本来就在记。**保的是供给侧的命** |
| 3 | **同一空间的时间线**(空间有限,时间无限) | **比想象的低**——DB 里本就有 `created_at`,是排序展示问题 |
| 4 | 空间内锚点留言(文字/照片/语音) | **真的贵**(3D锚点+输入+审核+通知),往后排 |

**⚠️ 用户曾担心"文字评论会让服务器爆炸"——算过账:一条100字中文≈300字节,100万条≈300MB≈12个SPZ场景。文字是最轻的,轻两三个量级。真正该盯的是 CDN 流量(一个场景25MB × 播放次数)。**

**不管用的:** 收藏/点赞/排行榜是留存的**装饰**不是引擎,很多产品在这上面浪费半年。

**一个重要发现:物体档(30s扫/10-15s看)最接近短视频比例且可批量 ⇒ 物体适合做"刷"(无限下滑流),房间是"访问"(目的地)。日常留存可能得靠物体流,比赛只是引爆点。**

## 4. 资产盘点(决定紧迫感的核心框架)

**起跑资产 100% / 护城河资产 0%**

- **起跑资产(会贬值)**:产品级端上管线、跨端先手、判死能力、验收能力、一人决策速度、零成本结构
- **护城河资产(会增值)**:客户、签约场地、在外流传的链接、内容库 —— **一样都没有**

> **手上全是会贬值的东西,一样会增值的都没有。这才是紧迫感的真身,比"被抄"真实且更快到来。唯一的兑换窗口是发布和跑客户。**

**用户已完全对齐此框架。**

**用户独有的组合优势(三个顶点的人都到不了):** 大公司决策慢成本重;有钱的团队会选云端从而永远失去零边际成本;一个人的团队通常做不出产品级端上管线。

## 6. 跨端与通用位姿层(当前最大的开放技术议题)

**用户的硬要求(08-21):** 以后无论什么品牌手机、AR 眼镜、机器人,管线要能直接适配。**"国行机型逐个实测"绝不允许发生。**

### 🔴 T0 覆盖决策(08-21,晚于并覆盖本节旧措辞)

**ARKit 只允许作为实验对照,绝不是最终架构的一部分。** 同理,ARCore、AREngine、厂商眼镜 SDK、机器人厂商里程计等产出的 pose/depth/mesh/tracking/relocalization,都不得成为生产计算图的输入、初始化、尺度锚、失败兜底或静默回退。`ARKit_POSE_REMOVAL_GLOBAL_RESEARCH_2026-08-21.md` 中“平台位姿可选先验”的建议只适用于隔离实验臂,其产品结论被本条覆盖。

**允许的跨端差异只有原始采集薄适配层:**各系统用公开相机/传感器 API 提供 RGB、单调时间戳、与实际图像对应的内参/畸变/裁剪/方向、原始陀螺仪与加速度计、标定 epoch 和能力声明。时间同步、标定、关键帧、mask、估姿、尺度/重力恢复、回环、全局优化和重建必须由同一套自有或许可放行的品牌无关核心完成。LiDAR、专用深度芯片和厂商 AR 能力不是最低契约。

这里的“任何品牌”严格指**任何能通过公开 API 满足最低原始传感器契约的设备**,不是声称缺少必要传感器、时间戳或系统权限的任意硬件也能得到相同物理质量。不得做品牌白名单或品牌专用算法分支;只能做能力检测、明确拒绝不满足契约的设备,并持续扩大能力覆盖。

**T0 产品候选只有:**
- **B2:**关键帧、mask、初始化、尺度/重力、求解和下游均不读取任何厂商 AR 派生资产;
- **B3:**采集期生产 target 不链接、不启动、不调用 ARKit/ARCore/AREngine 等厂商 AR 会话;
- **X:**iOS/Android/鸿蒙及后续眼镜/机器人适配器使用同一版本化算法核心、行为契约、模型族与 I/O schema。不同算力可使用已声明、已验收的 kernel/量化/资源配置,但设备能力必须作为数据进入统一策略,不得按品牌分叉估计逻辑或放宽质量门槛。

A(当前 ARKit)是冻结基线;B1(仅关求解器 pose)是定位依赖的诊断臂;C1/C2(ARKit seed/soft prior)是研究上限。**A/B1/C 永远不能升级为生产候选。**若 B2/B3 暂时不如 A,结论是继续改进许可清洁的开源/自有算法,不是把厂商先验留进产品。

**发布质量门:**在冻结的跨品牌配对场景集上逐场景比较 A 与 B2/B3/X;先用重复运行测出噪声地板,再预注册单侧非劣检验。生产候选的收敛率、注册/连通率、轨迹、几何、下游画质和热/时延均不得出现超出噪声地板的退化;至少一个用户可感知或几何主指标应升级。不得用总体平均掩盖某品牌或困难场景失败,也不得静默切回厂商 AR。

### 市场事实(2026 Q1,已核实)
- **Android 约 63% · 鸿蒙 19%(已连续 7 季超 iOS) · iOS 不到 19%**
- 品牌(2026H1):华为 20.6% > 苹果 17.5% > OPPO 16.2% > vivo 15.6% > 小米 14.3% > 荣耀 11.8%
- ⚠️ **做了 Android ≠ 覆盖华为**(华为新机是鸿蒙),实际覆盖 OPPO+vivo+小米+荣耀 ≈58% + 华为老机型
- **旧结论“鸿蒙不做”已被 T0 覆盖:**市场首发顺序仍可另定,但技术架构不能排除任何品牌/系统;鸿蒙也只能接同一品牌中立核心,不能另建厂商算法分支

### T0 架构方向(最小输入契约)
```
生产必需输入:图像序列 · 精确时间戳 · 内参/畸变/图像几何 · 原始 IMU · 标定/能力声明
生产禁止输入:任何厂商 AR pose/depth/mesh/tracking/relocalization 及其派生资产
实验隔离输入:可保存厂商位姿,但只能进入 benchmark target 的 A/C 对照臂
品牌中立核心:同步/标定 → 位姿/尺度/重力 → 回环/全局优化 → 重建
输出:带坐标系、尺度状态、置信度和版本的位姿 + 重建
```
**核心转变:把厂商位姿从生产输入中删除,位姿只由品牌中立核心输出。** 新设备接入仍须验证同步、标定和能力契约,但不得改核心算法或维护品牌白名单。

**成本可能比想象低:用户已有 GPU 特征提取、匹配、PnP、IMU 处理和一条流式 SfM——流式 SfM 本身就是位姿估计器**,问题是够不够快够不够稳支撑拍摄期引导,不是从零工程。

### 🔴 下一步立即实验 + 不可取消的 T0 终点
**先关掉 ARKit 位姿,测 SfM 还收不收敛、慢多少。** 这仍是最低成本的第一项诊断,但它只决定品牌中立核心的差距和改进顺序,**不决定是否继续摆脱厂商依赖**。随后必须完成 B2、B3 和跨端 X;在它们通过前,混合 ARKit 路线只能留在实验环境。

| **UGC 内容审核** | 《网络信息内容生态治理规定》列举式义务 | 要建:信息发布审核/跟帖审核/版面生态管理/**实时巡查**/应急处置/谣言黑产处置;**显著位置便捷举报入口 + 必须反馈处理结果**;公开管理规则与平台公约;用户账号信用管理制度 |

### 信息源纪律
- **二手英文源对中国产品的判断经常错** — 英文搜索因 App Store 同名条目(Kios Inc. 的自助终端管理 App)误判"Remy 不是鸿蒙独占"。**判断中国产品必须抓中文一手源并核对开发者主体**
- **代办机构口径 ≠ 政策** — 高企"需要15-18件专利"是代办网站的营销话术,政策的硬门槛是评分表那五行
- **用户对自己项目的技术事实比 AI 准** — 一场对话被正确推翻五次(Remy独占/外包也能交付链接/技术栈是Dart/失败方案对方不需要知道/"我是做平台的")。**他反驳时先假设他对**

## 8. 知识产权策略(四层分工,别混)

| 层 | 方式 | 要点 |
|---|---|---|
| **UI/交互** | **外观专利 + 商标** | 一看就懂,保密在法律上不成立(自拍杆那一类)。**按视觉相似度分组**,不是按界面/功能类别;一件最多装 10 项相似设计;"同一产品"卡得很死。产品名格式:`用于手机的三维扫描引导动态图形用户界面`——必须带载体+用途,动态的要有"动态"字样、不少于三帧、标注触发条件。**GUI 不用六视图**,一幅主视图即可;**美国 2026-03-13 新指南已取消"必须画显示面板"的要求** |
| **算法** | 发明专利 1–2 件,**不为防御** | 审查 2–3 年,保护的是两年前的做法。真实用途:高企 Ⅰ类 7–8 分、融资资产计数、收购筹码 |
| **参数/SOP/阴性结果** | **商业秘密** | 三要件:秘密性、价值性、**保密措施**(缺的是第三个)。**举证责任倒置**——只需先证明采取了保密措施,"不为公众所知悉"由被诉方证伪。动作:核心参数与SOP单独存放标密级、协作者签保密协议、分模块交付(`.a` 隔离已是雏形)、访问留痕 |
| **数据/客户/场地** | 合同 + 时间 | 不是知识产权,但最抄不走 |

**中美费用对比(单件全包):中国 ≈2,000–3,000 元 / 美国 ≈$1,500–5,000(micro entity + 线上渠道 + 自己出图可压到 ≈$1,400)。差 5–10 倍。**
- 美国设计专利:平均 pendency **21.5 个月**(首次 OA 16.9 个月),**加速审查 7.7 个月**;驳回率仅 **17%**(发明专利 86%);**不需要维持费**(中国要年费)
- **策略:中国全报,美国只挑 1–2 件核心走 6 个月优先权。优先权本质是个 6 个月的期权,行权价约 1 万元/件**

**高企认定:知识产权 30 分 = 技术先进性 8 + 对主营核心支持 8 + 数量 8 + 获得方式 6(+标准编制 1–2)。数量档位:1项Ⅰ类=7–8分 / 5项以上Ⅱ类=5–6分 / 3–4项Ⅱ类=3–4分 / 1–2项=1–2分。⇒ 软著做到 5 项就到顶,跨到 7–8 分只能靠 1 件发明专利。别堆数量——先进性+关联性 16 分是数量的两倍,而这两项天然占优。**

## 10. 冷启动打法(抖音小红书史料,只留可迁移的)

1. **种子人群精准且自带圈层** — 抖音第一批是**各大艺术院校的时尚年轻人,不是明星**
2. **最硬的激励是曝光的确定性,不是钱** — 抖音赢快手靠**中心化分发,新人也能爆**。钱花完就走,曝光让人留下
3. **降低门槛靠机制不靠喊** — 挑战赛本质是"不用你想创意,跟着做";抖音连爆款音乐都替创作者打磨好
4. **用排除定义社区** — 小红书早期**明确不欢迎代购**。可迁移:只收真实拍摄,**不收效果图和渲染图**,零成本立刻有辨识度
5. **明星是第二步不是第一步** — 顺序反了明星发完就走。抖音 2017-08 起办线下巡回派对,**归属感是线下建立的**
6. **微视的教训**:腾讯有钱有流量有算法有专利,砸巨额补贴仍输。复盘原话:**"内容型社区的核心体验没法靠策划功能、砸钱买资源实现——用户要的不是功能不是官方内容,是其他用户的 UGC"**。失败主因是达人不足、定位反复、错过时间窗口、赛马失效——**没有一条跟算法有关**

## 11. 组织与融资

- **股权**:用户"三年以上员工才谈股权,投资方可以入股"。**代价是招不到 A 级人才**,且定价可能反了(给钱的人门槛低,一起扛的人门槛高)。**四年 vesting + 一年 cliff 就是为"信任需要时间"设计的**:满12个月一次性兑 1/4,之后每月 1/48,不满一年走人一股不带。**一年就够,不用等三年**。建议先给 5% + 里程碑追加
- **融资环境**:2026 被称为过去三年最友好,硬科技领跑早期,**"即便仅有专利储备与产品原型方案,资本也愿意买单"**,部分项目"三月一轮"(来源多为知乎盘点/财经媒体,有推广色彩,当方向参考)
- **用户的融资计划**:做到 **1000 个跑通训练管线的人**(不是发布的人)后拉融资
  - 漏斗粗估:下载→打开70%→开始扫描50%→完成60%→重建成功80% ≈ **17%** ⇒ **1000 次成功重建 ≈ 6000 次下载**,几周到两三个月可达
  - ⚠️ **缺一个维度**:1000人各跑一次 vs 100人各跑十次意义完全不同。建议配 **人均重建次数 / 7日二次重建率**
  - 🔴 **顺序不能反:先把重建成功率钉住,再开闸拉量。** 成功率 50% 时拉量 = 烧掉不可再生的用户(每人对新 App 只给一次机会)
- **钱该买什么**:买内容供给和你的时间 ✅ / 买开发速度 ❌(招人3个月+磨合3个月,前半年反而更慢)
- **服务器成本不是障碍**:腾讯云 COS 0元开通送50GB+10TB;阿里云轻量38元档不限流量;**前期服务端一年一两百块**。用户曾把"租显卡"和"做平台"的成本混为一谈

## 12. 当前待决问题(按紧迫度)

1. 🔴 **T0 品牌中立主链:**先做 A/B1 测“关掉 ARKit pose 后是否收敛、慢多少”,随后无条件推进 B2(端到端无厂商派生资产)、B3(采集期不启动厂商 AR)和跨端 X。A/B1 只诊断差距,不拥有改变终局的否决权
2. 🔴 **App 里能不能刷别人的内容?** — 能刷⇒必须IAP(实收68-69%);不能刷⇒网页微信支付一分不抽。**这条直接冲突"物体流可刷"的留存设计**
3. 🟡 **冷启动选哪个城市** — 要能亲自跑 + 产业密度 + 自己的人脉,分量比很多技术决策重
4. 🟡 **跨端发布时机** — iOS 可继续承担冻结基线和小范围实验,但不能形成 Apple-only 的产品主链。Android/鸿蒙验证按同一原始传感器契约、同一核心和跨品牌配对指标推进;市场首发顺序可另定,对外宣称跨端前必须通过 X。**"全国最乱的房间"不能在只覆盖不到19%时打出去,引爆机会是一次性的**
5. ⚪ **唯一没答案的战略问题**:放大到通用 C 端 UGC 后,**创作者凭什么给你做内容?** —— 婚庆商家动机是获客,通用创作者赚不到钱就得靠虚荣心,而虚荣心需要先有观众。**但"一次性时刻"这条线可能已经回答了它:创作者的动机不是赚钱,是不想失去**

## 13. 与用户协作的 Tips

- **永远用中文回复**
- **不捏造版本号、不乐观估时**;推断当 fact 是错的,**先联网查**
- **查资料优先联网核实**,尤其中国产品要抓中文一手源
- **他反驳时先假设他对**
- **他明确重复第二次的前提,立刻换框架,别再论证**(如"我是做平台的"说了三次)
- **规模感**:他每次把规模砍小,问题都自解。反过来——**当他觉得某事做不了时,先检查是不是把规模想大了**
- **不要用户可见的质量滑杆/档位**;**点云交付永远全量无损**;**永远不用 LiDAR**;**热稳定是硬约束**
- **能用 Dart 就用 Dart,少碰 Swift**
- **对照实验必须单变量**,先验证现有实现再自研
- 已发布的作战图 artifact 可原地更新(传 url 参数,同链接)
