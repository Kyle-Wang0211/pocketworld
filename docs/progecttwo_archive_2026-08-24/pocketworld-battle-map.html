已定 / LOCKED

八条不再重新讨论的决策

这些已经收敛。后面所有动作从这里推导,改动它们要重新推一遍下游。

公司形态
空间内容平台,靠 C 端流量。对标 Roblox——重创作工具 + 零门槛消费端 + UGC 经济。抖音小红书能成是因为足够轻,Polycam 是把轻的东西做重,所以长不出社区。Roblox 渲染也跑在用户设备上,与"算力全在端上"同构。
生意类型
内容生意,少做工具生意。工具生意(商家付费、终端免费)降级为纯现金流工具,不给战略地位。判断标准:它有没有在消耗做内容那条线的时间。
内容主轴
一次性的时刻。场地可重拍,"当天"不能。这是唯一一类先发优势随时间累积、后来者永远补不回来的资产——Matterport 有 1400 万个空间,但没有"某场婚礼的那一天"。
发布方式
工具与平台同日上线。入口型工具单独发是浪费。闭门期的产出就是首发那天平台上的内容库——平台首发不能是空的。
算力位置
全部在端上,不租不买显卡。结构性优势:边际成本趋近于零,云端对手成本随规模线性涨。全球显卡供不应求,不跟巨头抢。也是技术平权。
厂商合作
不做。不依赖任何一家的硬件或生态。Remy 被锁死在鸿蒙上就是代价。而 08-22 的 B1 实验已经证明:厂商中立在几何上基本是免费的。
地理数据
场景只挂地址文本,绝不挂经纬度。不构成地理信息系统,把测绘资质问题合法推后到 preA。这条纪律换来的是时间,免费且不影响体验。
跨端原则
同一核心、同一 schema、同一验收门。不同算力可以有声明过的 kernel/量化/资源配置,但不得按品牌分叉估计逻辑。"国行机型逐个实测"绝不允许发生。

本周就要动的三件事

  1. frame59 最小独立分诊 —— 不重跑 SfM、不改 solver、不改阈值,只离线重做 matching + geometry verification。判定是"live 尾帧 flush 问题"还是"内容重叠退化",跑之前不许预设答案。
  2. 启动域名 + ICP 备案 —— 有审核周期,是最容易卡死首发日期的一件事,而且不占开发时间。
  3. 软著登记 + 外观专利在发布前报掉 —— 公开即丧失新颖性,这条不可逆。

后两件不需要写一行代码。第一件是整条技术主线的地基。

核心结论
求解器完全看不到 ARKit sidecar / pose_priors / gravity registry 时,能重复收敛到 57/60。共同注册部分没有整体崩坏,主要回归集中在帧覆盖。这把"通用位姿层"从"要不要冒险"变成"已有证据支持"——直接降低 Android 风险、改写融资叙事、并证明"不逐个机型适配"是可达的。
A 的 60/60 是虚的
frame_000059:1547 keypoints,但 0 matches / 0 TVG edges / 0 observations。ARKit 能把它当 pose-only 相机带进模型,但造不出几何;最终 FilterFrames(min_num_observations=1)把零观测相机注销。⇒ A 的最终几何 coverage 也是 59/60,真实差距只有 2 帧。
那 2 帧是门槛
frame38/40 可见 3D 点仅 15/16 个,未达 absolute-pose 最少 30 inliers,从未进入 PnP。是阈值门槛,不是算法失效。处置方向已定:先补时间邻接、回看匹配、弱段候选,不先降 30-inlier 门槛——手上正好有 track 延长那把刀,只差十几个点正是它擅长补的。⚠️ off-by-one:日志 Registering image #38/#40 是 DB IDs,对应 frame_000037/039。
时间代价
反事实端到端 ≈ +34.5%(11.58s → 15.57s,多约 4 秒)。在"拍完 30 秒出云"的预算内 ⇒ 厂商中立的时间成本付得起。 ⚠️ 但这是 counterfactual 加法不是实测:A/B1 用不同公共入口,A comparator 的 35.96s 被 rematch enrichment 污染。严格 slowdown 仍 unresolved,绝不能对外宣传任何提速倍数。
正确命名
B1 solver pose-off / gross convergence smoke。不是端到端 ARKit-off、不是 vendor-neutral 完成、不是 B2、不是跨端核心已验证。残留泄漏:frozen 565-edge TVG 来自采集期 mandatory-gravity estimator;keyframe/pairing/TVG 内点仍有厂商 provenance;capture 时仍启动了 ARKit session。

冷启动 / 用户自己提的方案

征集"全国最乱的房间"

比我给过的任何冷启动方案都好,好在四个地方。

为什么成立
它把隐私抗拒反转成了参与动机。① "乱"不是隐私是笑点,展示不是暴露是自嘲 ② 消灭 UGC 头号杀手——门槛不是降低而是反向,越糟越好 ③ 3D 在这里是必需而非装饰:乱是空间性的(层叠、无处下脚、门后还有一堆),2D 照片根本拍不出来 ④ 排名/对比/嘲笑是现成的传播燃料。
变现设计
DDL 后点赞第一名获"人民的选择 + 官方认证",该作品 0.99 元卖门票,同时开启创作者分成。第二三名及其他全免费 ⇒ 传播不受损,付费墙本身变成传播素材。但要清楚:这一步的产出是叙事资产不是财务资产——"3D 内容能卖钱"这个证明值钱,那几百块不值钱。
必须配套
参赛必须用自家工具,产出留在平台可检索;埋 before/after。"收拾完再扫一次"一个动作同时做到:产生第二次创作、before/after 自带二次传播、而且它天然是"一次性时刻"——把猎奇冷启动和内容战略接上,不然是两张皮。⚠️ 提防用户属性错配:看热闹的人不会为"我的婚礼"付费,很多平台死在靠猎奇起量后转不了型。
隐藏的大价值
乱房间是三维重建的地狱难度场景。严重遮挡、小物件密集、杂乱重复纹理、狭窄空间小视差、光照差——B2 需要的 10 类恶劣场景它天然覆盖大半,而且样本是用户自愿送上门的。⇒ 这场比赛可以当 B2 的大规模回归验证集,不只是市场活动。建议内置失败上报,单开"连算法都放弃了"奖项——把技术失败变成内容笑点,拿到最珍贵的负样本还不掉口碑。
必须验证的假设
"愿意分享私人空间"的前提是匿名。要匿名参赛 + 默认剥离一切位置信息——正好与那条地理数据红线一致,同一个设计既合规又提升参与率。⚠️ 审核压力陡增:乱房间里会扫到证件、药盒、别人的脸,而用户自己都不会细看。上传前的自动模糊/提醒是必需品。
留存 / 爆款 ≠ 留存,这是两件事

让老内容重新值得看

真实生产/消费比是 1.5:1 到 3:1(物体 30s 扫 / 10–15s 看;房间 3–5min 扫 / 2–3min 看;单次扫描上限 300 帧或 5 分钟)。但真问题是:1% 创作者要养 99% 消费者,而 3D 场景的重复消费率接近零。

01
周期性主题 —— 开发成本零本周书桌 / 下周冰箱 / 再下周车后备箱。把一次爆款变成心跳。抖音的挑战赛就是这个机制:不是一次,是永不停的一串。同时解决供给——每周给一个再扫一次的理由。
02
访客反馈回流给创作者 —— 成本极低"37 人看过你的房间,平均停留 1 分 12 秒,最多人停在你的书架前"。后端本来就在记,只是给创作者看一眼。对内容平台,创作者留存比消费者留存更值钱——而创作者要的是反馈,不是内容。抖音的核心留存从来是"我发的东西有多少人看"。
03
同一空间的时间线 —— 比想象的便宜空间有限,时间无限。我的房间一年前 vs 现在;装修中的房子每周一扫;孩子的房间从三岁到八岁。DB 里本来就有 created_at,这是排序展示问题不是新数据结构。而且每一次扫描天然是那一刻的唯一记录,与"一次性时刻"是同一件事。
04
空间内锚点留言 —— 真的贵,往后排3D 锚点 + 输入 + 审核 + 通知。⚠️ 但"文字会让服务器爆炸"是虚惊:一条 100 字中文 ≈ 300 字节,100 万条 ≈ 300MB ≈ 12 个 SPZ 场景。文字是最轻的,轻两三个量级。真正该盯的是 CDN 流量(一个场景 25MB × 播放次数)。
不管用的
收藏 / 点赞 / 排行榜。它们是留存的装饰不是引擎。没有前三条,加再多社交按钮也留不住人——很多产品在这上面浪费半年。
一个被埋没的机会
物体是"刷",房间是"访问"。物体档(30s 扫 / 10–15s 看)最接近短视频比例,而且可批量——一个人一下午能扫二十个。门槛最低、隐私风险最小、审核最容易。比赛负责引爆,日常留存可能得靠物体流。
营收 / 内容生意的三层

钱从哪来,顺序不能倒

01
现金流工具(现在,不给战略地位)接 B 端拍摄/制作单子养活自己和买时间。你不是中间商是总承包——外包交付一堆文件,你交付一个能用的东西(微信适配、访客统计、多场地管理、随时更新),这段差距就是定价空间。⚠️ 设时间占比红线(如 30%),否则变成外包吃掉全部时间,这是 bootstrap 最常见的死法。
02
内容付费(比赛验证)冠军作品门票 / pay-what-you-wish 支持创作者 / 创作者分成。博物馆的数据说明:能收上钱的从来不是"静态可自由浏览的场景",而是多了点东西的——有人(讲解、陪同)或进不去(私人档案、幕后)。随意付可能比固定价更赚钱且不劝退观众。
03
平台变现(有流量之后)撮合、推荐位、订阅。当用户开始主动来平台比较,谈判地位才反转——"比较"是单个创作者永远给不了的东西,这才是天然不可绕过的。早期强行截流 = 在最需要传播的时候关掉水龙头。
资产 / 这一条决定紧迫感

起跑资产 vs 护城河资产

你有的
起跑资产:100% — 产品级端上管线、跨端先手(现已有毫米级证据)、判死的能力、验收能力、一个人的决策速度、零成本结构。"产品级端上管线 + 零成本结构 + 一人决策速度"这个组合是稀缺的:大公司决策慢成本重,有钱的团队会选云端从而永远失去零边际成本,一个人的团队通常做不出产品级管线。三个顶点上的人都到不了这儿。
你没有的
护城河资产:0% — 用户、内容库、在外流传的链接、创作者关系。零外部用户、零收入、尚未发布。
为什么急
起跑资产会贬值,护城河资产会增值。技术会被追上或被 feed-forward 绕过;用户和内容越多越值钱,而且是复利。你手上全是会贬值的东西,一样会增值的都没有——这才是紧迫感的真身,比"被抄"真实且更快到来。唯一的兑换窗口是发布。
风险 / 按会不会杀死你排序

七个已识别的风险

高 · 产品前提

米制尺度

单目 B1 不原生提供米制尺度。 而核心商业差异化是"如视是 360 全景没有真实几何,我们能量尺寸、能排座位、能做布置方案"。没有米制尺度 = 不能量尺寸 = 那条差异化不存在。

处置 把"米制尺度 provenance"写进 B2 成功门,与 connectivity/coverage 并列。路径判据已有:深度/尺度先验只许四端皆有来源(IMU)——IMU 预积分是唯一四端全有的解。不然 B2 过了产品还是缺一条腿。

高 · 产品

3D 内容的消费时长

Roblox 一个游戏能玩几百小时。一个 3D 场景看完就完,重复消费率接近零。留不住人的平台不是平台,是画廊。Remy 加"实景特效视频模板"就是因为它们知道 3D 本身留不住人。

处置 留存机制那一节的前三条必须进第一版,尤其周期主题和访客反馈——它们是画廊和场所的分野线,且成本极低。

高 · 合规

测绘与众源地理信息

"基础地理信息数据的采集、存储、传输、处理需在具有测绘资质单位内部形成闭环"。监管在收紧。备案(事后登记)与资质(事前审批,要人员、设备、质量体系)是两件事。

处置 只挂地址文本不挂经纬度,不构成地理信息系统,合法推后到 preA。真要走 UGC 平台,这块必须找专业的人正式过一遍。

中 · 商业模式

IAP 分叉尚未决

App 里能不能刷别人的内容? 能刷 ⇒ 数字内容必须走 IAP,中国区实收 68–69%;不能刷 ⇒ 消费与付费全在网页,微信支付一分不抽(抖音自己就用网页版充值绕苹果税:iOS 1元=7抖币 vs 安卓 1元=10抖币)。

处置 这条与"物体流可刷"的留存设计直接冲突,必须在动手做比赛前拍板。建议先保持 App 纯采集——初期收入本就是叙事资产,被拒审的代价远大于那 31%。App 内不能有任何指向网页付费的按钮、链接或文字暗示。

中 · 分发

微信禁止 H5 唤起 App

URL Scheme 在微信、微博、QQ 浏览器、手机百度中均被禁用。提示"请在浏览器打开"的流失是灾难级。Android 还不支持直接识别 Scheme。

处置 别设计"网页跳 App"那一跳。生产者(创作者)有强动机主动下载,消费者根本不需要 App。Universal Link 在微信的实际放行必须真机实测,不听任何转述。

中 · 责任

数据责任转移 + UGC 审核

现在纯本地,数据丢了是用户自己的事。一旦平台托管,丢了就是你的事故。而扫描真实空间会带进别人的脸、别人的家、证件药盒。

处置 备份恢复进第一版。审核用"渲染多视角 2D 图 → 送现成内容安全 API"(《3D4ALL》列的四大难点对你四条全不成立,你的产物就是真实场景照片,现成 API 原生适配)。上传时必须勾选并记录"已获同意",带时间戳存档。删除必须给具体理由——不是道德要求是留存要求。

低 · 组织

股权定价可能反了

投资方可以入股,员工要满三年——给钱的人门槛低,一起扛的人门槛高。而钱哪里都有,那个人不一定有。

处置 四年 vesting + 一年 cliff 就是为"信任需要时间"设计的:满 12 个月一次性兑 1/4,之后每月 1/48,不满一年走人一股不带。一年就够,不用等三年。先给 5%,写清里程碑后追加。

格局 / 谁在场上

竞品与它们各自的枷锁

每一家的弱点都是结构性的,不是他们没想到。

唯一还没有答案的问题

通用 C 端创作者,凭什么给你做内容?

Roblox 有海量优质 UGC,因为创作者能赚到钱——那是个真实的经济体,不是情怀。放大到通用 UGC 之后,创作者赚不到钱就得靠虚荣心,而虚荣心需要先有观众,观众又需要先有内容。

但"一次性时刻"这条线可能已经回答了一半:创作者的动机不是赚钱,是不想失去。我的婚礼、我去的那场演出、孩子的毕业典礼——他不是在给平台供内容,是在给自己留东西,平台只是顺带得到了它。剩下没答的是:这个动机能不能撑起持续的、而不是一次性的创作。

技术栈 / 已确认的事实

四条不用再犹豫的技术判断

跨端
Android 是编译目标,不是重写工程;且已有 B1 的几何证据背书。Flutter/Dart 是应用层,WGSL 跑在 Dawn 上,Dawn 本来就把 WGSL 分发到 Metal / Vulkan / D3D12。ARKit 依赖高度集中在一个文件(ios/Runner/OfficialAetherARKitPlugin.swift,4336 行,全仓唯一 import ARKit),且暴露给 Dart 的 20 个 method channel 本身就是抽象契约。
位姿层
把位姿从"输入"变成"输出"。最小输入契约 = 图像 + 内参 + IMU(手机/眼镜/机器人全有);平台位姿(ARKit/ARCore/眼镜SDK)降级为可选先验。这样新设备接入成本 = 提供数据,国行白名单问题自动消失。⚠️ 开源 VIO 分两个阵营:ORB-SLAM3 / VINS-Mono / OpenVINS 是 GPLv3(上不了 App Store);Kimera-VIO 和 Basalt 是 BSD 可商用,但都是 stereo-inertial 且为桌面写的。
压缩
Draco 走点云/mesh,SPZ 走高斯泼溅。Draco 核心是 C++,官方带 iOS 工具链,原生 FFI 零拷贝解码比 WASM+Worker 更快——不需要"移植"。注意 Draco 为压缩率打乱顶点顺序会拖慢 GPU 渲染,网页端访客等不了,首帧时间常比压缩率值钱。渐进加载(先低模、停留超几秒再拉细节)的收益可能比再压 30% 体积还大。
双层架构
采集端 App,消费端网页。Scaniverse 就是 App 采集 + SPZ 格式 + web 端查看编辑。WebGL 覆盖 95%+ 设备。"工具是 App"和"链接在微信里能打开"是同一个产品的两端。这个架构同时也是绕开苹果 IAP 的合规路径。
知识产权 / 四层分工,不是二选一

专利与商业秘密怎么切

唯一判据:产品上市后别人能不能看出来。一看就懂的东西,"保密"在法律上根本不成立。

UI / 交互
外观专利 + 商标。⚠️ 公开即丧失新颖性,必须在发布前申请,TestFlight 算不算公开要专业确认。按视觉相似度分组报(不是按界面、不是按功能类别),一件最多装 10 项相似设计。产品名称:用于手机的三维扫描引导动态图形用户界面——必须带载体和用途,动态的要有"动态"字样、不少于三帧、标注触发条件。GUI 不用六视图,一幅主视图即可;美国 2026-03-13 新指南已取消"必须画显示面板"的要求。⚠️ 外观设计巴黎优先权只有 6 个月(不是 12),过期不可逆。
算法改进
报 1–2 件发明专利,但不为防御。审查 2–3 年,保护的是两年前的做法。真实用途:高企 Ⅰ 类那 7–8 分、融资尽调的资产计数、被收购时的定价筹码。
参数 / SOP
商业秘密,缺的是第三个要件。三要件是秘密性、价值性、保密措施。要动作:核心参数与 SOP 单独存放标密级、协作者签保密协议、分模块交付(.a 隔离已是雏形)、访问留痕。举证责任倒置——你只需先证明采取了保密措施。
中美与高企
中国全报,美国只挑 1–2 件核心走 6 个月优先权。单件全包:中国 ≈2,000–3,000 元 / 美国 ≈$1,500–5,000(micro entity + 线上渠道 + 自己出图可压到 ≈$1,400)。美国 pendency 21.5 个月(加速 7.7),驳回率仅 17%,且不需要维持费。高企:数量只占 8/30 分,先进性+关联性 16 分是数量的两倍且你天然占优——软著做到 5 项就到顶,别堆数量;网上"15–18 件"是代办机构口径不是政策。
冷启动打法 / 抖音小红书史料,只留可迁移的

五条不花钱的机制

种子人群
精准且自带圈层。抖音第一批种子是各大艺术院校的时尚年轻人,不是明星——爱表现、有审美、同伴圈层紧密,来一个带一群。
最硬的激励
曝光的确定性,不是钱。抖音赢快手靠的是中心化分发——新人也能爆。钱花完就走,曝光让人留下。
降低门槛
给模板,不是喊人创作。挑战赛的本质是"不用你想创意,跟着这个做";抖音连爆款音乐都替创作者打磨好。对你:给拍摄 SOP、给模板、前期甚至替他们拍。
用排除定义
小红书早期明确不欢迎代购。你不收什么,比你收什么更能定义你是谁。比如只收真实拍摄、不收效果图和渲染图——在一堆 PS 精修图里立刻有辨识度,成本为零。
微视的教训
腾讯有钱有流量有算法有专利,砸巨额补贴仍输。复盘原话:"内容型社区的核心体验没法靠策划功能、砸钱买资源实现——用户要的不是功能不是官方内容,是其他用户的 UGC"。失败主因是达人不足、定位反复、错过时间窗口、赛马失效——没有一条跟算法有关。
