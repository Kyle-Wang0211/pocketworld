# 12MP 匹配深度塌陷:修复候选决策材料(待用户裁决,2026-09-02 夜)

侦探全文:`2026-09-02-match-depth-collapse-diagnosis.md`(重放实测,尺子先过阳性对照:主机重放 vs build89 设备逐位一致)。

## 判决(已复核关键锚点)

塌陷主因 = **8192 特征预算在 12MP 全幅下把整个细尺度族(octave 0)裁没了**。
死亡地点全在 ratio 检验:8192 →(max_distance 门 0 杀伤)→ ratio 0.8 门 256/544 →
互检 152/358 → TVG 存活 82-93%(验证层无罪)。每对 verified 中位仅 136-146 = 预算 2%。

## 🔴 与匹配器移植的根本区别:这条线全是质量交换,不是纯无损

匹配器 WGSL 移植能自主推进,因为它**逐字节对拍现役输出**(696/696 全等)—— 无损是可证的。
深度修复**没有一个候选是构造上纯增益**,且多数**偏离 COLMAP 默认**。按"绝对无损"+"只抄
COLMAP"两条红线,**不能自主上机,须用户裁决 + 真机 A/B**。逐候选:

## 我的读法(供裁决,非替你决定)

- **R4 是唯一不撞红线的候选** —— 严格抄上游默认。但它在饱和场景(正是我们的场景)的净效应
  **没实测**,方向双刃(降检测分辨率 vs 减轻裁剪),必须真机 A/B 定生死。它也与你 07-11
  "4224→3200 降档提案被否决(不能有损质量)"的签决**正面冲突** —— 那次否决的正是降分辨率。
- R1 表面"零成本 +43%"最诱人,但它是**主动偏离上游默认的质量滑杆**,双重踩线(禁质量滑杆
  + 偏离默认);外点多进来,下游浮点风险按 08-11 先例不可低估。
- R2 收益最大(×3.12)但死史最重,且"在树已实现默认关"本身就是当年判死的结果 —— 重开等于
  推翻 08-11 签决,须你亲自拍板 + 三门齐上。
- R3 是"回到 COLMAP 8192+3200 搭配"的另一半(R4 是降图,R3 是升预算),两者其实是同一个
  "8192 vs 12MP 失配"的两个解法方向。

## 结论:这条线今晚封在这里

四个候选全部需要**你 + 真机**。今晚(手机不在)不自主推进任何一个 —— 它们不是"极致无损提速",
是"质量/成本交换",超出你授权自主执行的无损范围。明早连同匹配器前沿判决一起摆给你选。
