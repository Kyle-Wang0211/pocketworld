# Design

The experiment separates backend effects from structural effects. OpenZL, ALP and WebGraph each receive a typed minimum unit extracted from the same frozen SQLite database and compete against a same-input ZPAQ method 5 baseline. Only an exact local winner may replace that member codec in WorldPack.

OpenZL uses a real parser and both the official ACE and clustering-plus-ACE workflows. ALP receives homogeneous IEEE bit-pattern columns. WebGraph receives normalized adjacency lists plus complete reversible node/order mappings. Every decoder dependency and sidecar is persisted and counted.

WorldPack is a PocketWorld-owned append-only chunk container. It stores the smallest verified candidate per semantic member, falls back to ZPAQ where new candidates lose, and validates each chunk before exposing data. It runs on a minimum mixed fixture, an approximately 100 MB prefix, and then the complete frozen capture. Host evidence cannot promote production.
