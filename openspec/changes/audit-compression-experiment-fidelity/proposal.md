# Proposal: Audit compression experiment fidelity

Prior compression discussions mixed complete official measurements, partial configuration screens, local research prototypes, and candidates that were only mentioned. This change adds a host-only evidence audit and minimum-unit supplements so unsupported winner/loser claims cannot guide production.

The audit does not change archive formats or application behavior. It records official upstream identity and semantics, evaluates the durability of prior evidence, and permits a single minimum-unit supplement only for a previously decision-bearing gap with a runnable official implementation.
