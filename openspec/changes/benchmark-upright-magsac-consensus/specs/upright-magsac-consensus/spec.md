## ADDED Requirements

### Requirement: The gravity-constrained upright model is immutable

Both consensus arms SHALL use the existing gravity normalization, normalized
bearing rays, PoseLib upright three-point minimal solver, deterministic sample
order, and squared Sampson residual.

#### Scenario: Experimental consensus generates a hypothesis

- **WHEN** the MAGSAC arm evaluates one minimal sample
- **THEN** the pose is generated by `relpose_upright_3pt`
- **AND** no generic essential-matrix estimator is called

### Requirement: Consensus behavior has one explicit boundary

The incumbent and experimental implementations SHALL receive the same ordered
upright-pose hypotheses and residuals. The experiment MAY change only scoring,
termination, weighting, and post-selection local optimization.

#### Scenario: The experiment is disabled

- **WHEN** no experimental C-layer selector is present
- **THEN** public status, pose, inlier indices, trial count, and deterministic
  fixture outputs match the incumbent implementation exactly

### Requirement: MAGSAC behavior has pinned provenance

The experimental score, termination rule, weight function, constants, and
local-optimization behavior SHALL identify their exact OpenCV 5.0.0 source and
SHALL pass fixed provenance vectors produced by that source.

#### Scenario: Upright model cannot expose one upstream operation

- **WHEN** an OpenCV MAGSAC operation cannot be reproduced without changing the
  geometric model
- **THEN** the implementation records an explicit deviation
- **AND** it does not claim exact upstream reproduction

### Requirement: The homography branch remains unchanged

The first MAGSAC experiment SHALL NOT change COLMAP homography estimation,
planar classification, watermark handling, match order, or status mapping.

#### Scenario: Upright MAGSAC arm completes

- **WHEN** its pose consensus returns a valid or pending result
- **THEN** the existing separate homography path receives the same options and
  matches as the incumbent arm

### Requirement: Initial MAGSAC evidence is host-diagnostic only

The first implementation SHALL remain default-off and SHALL stop before phone
installation. Host replay MAY verify determinism, model isolation, and a
credible performance direction but SHALL NOT select a production winner.

#### Scenario: Host candidate is faster and passes fixtures

- **WHEN** all host tests and diagnostics pass
- **THEN** the result remains research-only
- **AND** a separate reviewed phone experiment and device authorization are
  required before any production claim

### Requirement: GC-RANSAC is excluded

The experiment SHALL NOT add spatial neighborhoods, graph-cut energy,
GC-RANSAC dependencies, or a GC-RANSAC arm.

#### Scenario: A proposed change requires spatial coherence

- **WHEN** consensus behavior depends on a correspondence-neighborhood graph
- **THEN** it is rejected from this change
- **AND** the upright-MAGSAC experiment remains unchanged
