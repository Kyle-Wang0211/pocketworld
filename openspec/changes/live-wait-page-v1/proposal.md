# live-wait-page-v1 — 拍完即 3D viewer:关灯了,点云还在原地

日期 2026-09-15。用户原话:"结束拍摄后直接变成 3D viewer 页面。从拍摄退出的那个角度固定,就是说拍摄时候镜头的
位姿变成了 3D viewer 的位姿。然后点云状态实时更新。就是让用户感觉到其实只是关灯了,看不见物体了,但是物体表面的
那层点云还在原地覆盖着。" 产品逻辑:像 Uber 一样给确定性,不看黑屏无休止等待。

## 用户签决(本次)
- 位姿只固定**初始**,用户随时可转;做完后的浏览页(保存草稿 | 下一步、右上角选区编辑)一个像素不动。
- 中间版本点云没颜色就用**白色**(和拍摄期 AR 层一样),refined 到了换真彩。
- 顶部**不要任何状态条**(连"重建完成 · N 点"也不要);底部一颗胶囊显示倒计时。
- 倒计时:开头可显示"计算中…";**一旦给出就不再改**;粗粒度("不到一分钟" / "约 N 分钟")。
- 从个人页再进项目走同一页(后台在跑就看到正在跑)。这一版只改拍完那一段;再进入 = 下一步。
- 稠密、mesh 以后接同一页(第 4 条);这一版稠密仍在"下一步"启动、最后出一版云。
- 倒计时算法**不许按本机中位数自研**;先全球联网查,能复刻的直接复刻(见 design.md 的出处表)。
- 全局 BA 的 Ceres 逐迭代计数这次不动核。

## 范围
Dart-only(App.framework 覆盖安装,基线 = 机上 162)。不碰 Swift、不碰 PWOfficialSfm。
